# 示例数据（全部为虚构）

⚠️ 本目录下的所有商品、品牌、评论、供应商和价格**都是虚构的**，只用于演示导入流程和录制演示视频。
它们不代表任何真实产品或市场情况，不能作为选品依据。URL 均使用保留域名 `example.com`。

真实数据请放在 `private/imports/`（不会上传 GitHub）。

| 文件 | 内容 |
|---|---|
| `products.csv` | 竞品（key 用于在评论里关联商品） |
| `evidence.csv` | 评论 / 讨论 / 笔记等证据，每行必须有来源和采集日期 |
| `quotes.csv` | 供应商报价 |
| `evidence_bad_rows.csv` | 故意包含错误的文件，用于演示校验 |
